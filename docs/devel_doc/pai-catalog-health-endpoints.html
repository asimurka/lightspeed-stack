PAI migration — catalog & health endpoints

Lightspeed Core Stack (LCORE) · OGX removal · Oct 2026

Companion to providers registry. After PAI, inference is in-process — no OGX sidecar. That kills degraded mode and simplifies readiness.

Drop /v1/providers. Keep tools / info / readiness as LCORE-owned. Readiness = local registry + default model. No remote health pings. No degraded mode.

1. Summary

Endpoint Action

GET /v1/info Keep — name + service_version only; drop ogx_version

UI inference catalog stays GET /v1/models (registry §8).

2. GET /v1/providers — remove

Today: proxy of client.providers.list() by OGX api. Unused by query / Responses / MCP / RAG. Only internal users: readiness health walk and file-search discovery — both move off this API.

No replacement. Inference → provider_id on /v1/models. Vector stores → their own endpoints.

tool_runtime is unnecessary. MCP and file-search are on automatically when configured — not plugin rows:

  • MCP — mcp_servers → /v1/mcp-servers, /v1/tools, agent toolset. No model-context-protocol provider.
  • File-search — LCORE RAG / vector-store path (separate feature). No inline::file-search provider.

Delete handlers, auth actions, response models, tests. Do not rebuild a multi-API inventory.

3. GET /v1/tools

Today: MCP + agent capabilities (local) + file-search via OGX providers.list() (builtin_tools.py).

This feature: remove the OGX client. Keep MCP + capabilities and the response shape. Stop calling get_file_search_tools (OGX-only today). File-search rows return in the vector-store feature from LCORE config — see tools / MCP / file_search.

4. GET /v1/info

Today returns ogx_version from inspect.version() and 503s if OGX is down. After: name + service_version only. Delete ogx_version (prefer clean break + OpenAPI regen). No fake backend version.

5. GET /liveness

Unchanged (alive: true). Do not fold readiness checks into liveness.

6. GET /readiness

6.5 Degraded mode disposal

Sidecar-era escape hatch (LCORE-1856). Delete degraded_mode.py, allow_degraded_mode, metric, startup branch, readiness early return, docs/examples.

Cannot build default inference → do not take traffic. Fail startup or readiness — never “degraded but ready.”
