PAI migration — Streaming query interrupt

Lightspeed Core Stack (LCORE) · OGX removal notes · Oct 2026

How POST /v1/streaming_query/interrupt should work after OGX removal: use pydantic-ai’s first-party cancel path, keep the public HTTP / SSE contract, and let harness StepPersistence own agent-history snapshots.

Assumes the shared agent loop from Responses rewrite and the display vs agent-history split from conversations / compaction.

1. Today

Streaming query registers the ASGI task in StreamInterruptRegistry. The interrupt endpoint calls task.cancel(); the stream path catches CancelledError, repairs markdown, persists a partial turn, and emits an interrupted SSE event. Quota consume is skipped because that path returns before consume_query_tokens (not because usage is unavailable in principle).

1.1 Public contract (unchanged)

Request Outcomes
{ "request_id": "…" } from SSE start 200 interrupted=true|false · 403 not owner · 404 unknown

2. Decision

Recommended (PAI default): mint a per-request CancellationToken, pass it into the agent run, and cancel that token from the interrupt endpoint. Do not cancel the ASGI task for product interrupt.

3. How PAI cancel works

Documented stop gesture for a user “stop” button:

  1. Create CancellationToken() (fresh per run; single-use).
  2. Pass cancellation_token=token to agent.run / run_stream_events / agent.iter.
  3. From another request or task, call token.cancel().
  4. The run tears down (model stream closed, in-flight tools drained).

usage covers completed model requests; mid-stream usage for the request in flight is partial / provider-dependent.

Same first-party family: AgentRun.cancel(), RunContext.cancel(), AgentRunEvents.cancel(). Prefer the token when the stop comes from outside the run (our interrupt HTTP handler).

4. How LCORE triggers it

streaming_query │ ▼ token = CancellationToken() registry.register(request_id, user_id, token, conversation_id) │ ▼ async with agent.run_stream_events(…, cancellation_token=token) │ ├── SSE projector (deltas / tools) └── except RunCancelled: # not AgentRunResult display persist + interrupted SSE consume cancelled.usage deregister POST /streaming_query/interrupt │ ├── auth + ownership (unchanged) └── registry.cancel(request_id, user_id) → token.cancel()

The registry is only an ownership index for the second HTTP request (request_id → user + token). It does not cancel asyncio tasks. Keep stream_interrupt.py as the thin FastAPI surface (auth, OTEL, same response models); replace only the cancel call. 

token = CancellationToken()
registry.register(
    request_id,
    user_id=user_id,
    token=token,
    conversation_id=conversation_id,
)

try:
    async with agent.run_stream_events(
        prompt,
        cancellation_token=token,
        conversation_id=conversation_id,
        run_id=run_id,
    ) as stream:
        async for event in stream:  # deltas / tools; no result event on cancel
            yield project_lcore_sse(event)
except RunCancelled as cancelled:  # not AgentRunResult
    text, suffix = build_interrupted_response(
        extract_assistant_text(cancelled.all_messages())
    )
    await persist_display_turn(status="interrupted", text=text)
    consume_query_tokens(..., usage=cancelled.usage)
    yield token_event(suffix)
    yield interrupted_event(request_id)
finally:
    registry.deregister(request_id)

# interrupt endpoint (other request):
registry.cancel(request_id, user_id)  # → token.cancel()

5. Persistence

5.1 Agent history — StepPersistence

With harness StepPersistence on the agent, a token cancel is already persisted: cancel hits capability on_run_error (after_run is not called), which saves a continuable snapshot with state='interrupted'. LCORE does not need a second agent-history write in the interrupt path.

5.2 Display store — LCORE

The conversations / UI transcript is separate. On RunCancelled, the streaming projector still writes the display turn (status=interrupted), applies markdown repair, and emits the interrupted SSE event — same product behavior as today. StepPersistence is not the UI transcript.

6. Keep in mind

  • Default continue_run / latest_snapshot skip interrupted unless include_interrupted=True.
  • Display path (status=interrupted, markdown repair, interrupted SSE) stays LCORE.
  • Cancel before any model response may leave no snapshot (only run_started) and empty usage — nothing to consume.
  • Charge RunCancelled.usage for completed requests; do not skip the whole run’s usage because the user interrupted. Only the in-flight mid-stream remainder is best-effort.

7. Checklist

  1. Wire cancellation_token through the shared run builder (streaming query first; Responses stream can reuse later).
  2. Registry stores CancellationToken + ownership metadata; interrupt endpoint calls token.cancel() via registry.cancel.
  3. Projector: except RunCancelled → display persist + SSE; consume cancelled.usage; deregister.
  4. Rely on StepPersistence for agent-history snapshots; delete the ASGI task.cancel() / dual persist / uncancel interrupt path.
  5. Tests: owner cancel (200 + SSE + display interrupted + quota for completed usage); already-done; 403; 404; mid-tool cancel leaves an interrupted snapshot.
